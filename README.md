# Sauna Finder — Live Search MVP

## 今回の変更
- 条件＋「今の気分」から検索クエリを生成
- `/api/search` 経由でTavily Web Searchを呼び出す構成
- 検索結果に情報元リンクを表示
- Google Maps検索へ遷移
- API未設定時は既存のサンプルデータへフォールバック

## 無料運用
Tavilyの現行Freeプランは月1,000 API credits、クレジットカード不要。
Basic Searchは1検索=1 creditなので、試作段階ではかなり試せます。

## 公開時の設定
Vercel等にこのフォルダをデプロイし、環境変数 `TAVILY_API_KEY` を設定してください。
APIキーをブラウザ側に置かないことが重要です。

## 次の実装
1. 検索結果からサウナ施設だけを抽出
2. 温度・水風呂・外気浴・料金などを構造化
3. 条件一致スコアを算出
4. 「今日、どこでととのう？」のAI推薦を追加
5. 情報源と更新日時を表示
