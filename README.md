# Sauna Finder — Facility Search MVP v2

## 今回の変更
- Web検索結果の記事タイトルをそのまま施設名として表示する方式を廃止
- Tavily検索から「サウナ施設名」を抽出して候補化
- サウナ温度、水風呂温度、外気浴、料金、ロウリュ、タイプを本文から簡易抽出
- ユーザー条件との相性スコアを算出してランキング
- Google Mapsには記事タイトルではなく、抽出した施設名を渡す
- 情報元ページへのリンクも維持

## Vercel
環境変数 `TAVILY_API_KEY` を設定してください。
コード内にAPIキーを書かないでください。

## 注意
これはまだ「施設情報をWebから構造化するMVP」です。次の段階では、複数ソースの情報を統合し、施設ごとの情報精度を上げ、AIによる「今日ここが一番おすすめ」の文章生成を追加します。
