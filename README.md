# Sauna Finder v8

大枠→中枠→小枠のエリア絞り込みと、サウナ条件を組み合わせてWeb検索する版です。

## 構成
- `index.html`: エリア階層選択＋条件検索UI
- `api/search.js`: Tavily検索、施設名・住所・料金の検証、条件に応じた候補抽出

## 東京23区
- 都心：千代田・中央・港
- 城南：品川・目黒・大田・世田谷
- 城西：新宿・渋谷・中野・杉並
- 城北：豊島・北・板橋・練馬
- 城東：台東・文京・墨田・江東・荒川・足立・葛飾・江戸川

小枠は区を指定。未指定なら中枠全体、さらに中枠未指定なら大枠全体で検索します。

## 料金
- 時間制、入浴＋サウナ、サウナ利用、フリー料金を文脈付きで判定
- 料金条件指定時は、意味を確認できない料金を除外
- UIには `1時間 1,600円〜` のような料金ラベルを表示

## Vercel
既存プロジェクトの `index.html` と `api/search.js` を置き換えてコミットしてください。`TAVILY_API_KEY` は既存の環境変数をそのまま利用します。
